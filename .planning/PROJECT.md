# WanderWise

## What This Is

WanderWise is an AI-powered travel planning web app. Users describe a trip and get a day-by-day itinerary, personalized safety report, hotel suggestions, flight options, and ground transport — all generated by Groq's LLaMA model. A built-in concierge chat answers follow-up questions about any trip.

It is a full-stack TypeScript monorepo (React + Vite client, Express + Prisma server) targeting real paying users.

## Core Value

A traveler should be able to go from "I want to visit Tokyo for 5 days" to a complete, personalized trip plan in under 60 seconds.

## Context

**Stack:** React 18 + Vite / Express 4 + Prisma 5 / PostgreSQL (Supabase) / Groq (llama-3.3-70b-versatile) / Resend / Stripe (payment routes exist, SDK missing)

**Codebase map:** `.planning/codebase/` — 7 documents written Mar 22, 2026

**Key risks identified from codebase map:**
- Stripe SDK absent from package.json — any payment call throws at runtime
- JWT_SECRET env var cast to string without existence check — `"undefined"` becomes valid secret
- Groq JSON responses parsed directly into Prisma without schema validation
- `trip: any` in chat concierge bypasses TypeScript throughout the AI call chain

**Target:** Launch readiness — safe to put in front of real paying users

## Constraints

- **Stack:** TypeScript throughout — no runtime type erosion with `as any` workarounds
- **Auth:** Custom JWT (no OAuth provider) — must handle secret misconfiguration safely
- **AI provider:** Groq only (llama-3.3-70b-versatile) — no fallback model
- **Payments:** Stripe — must complete the partial integration, not replace it
- **DB:** Prisma + PostgreSQL (Supabase) — dual URL pattern (DATABASE_URL + DIRECT_URL)
